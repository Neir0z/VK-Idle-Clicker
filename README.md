# 🎮 VK Idle Clicker
Production-ready HTML5 Idle/Incremental game for VK Games & GitHub Pages.

## 🚀 Локальный запуск
```bash
# 1. Скачайте ES-сборку VK Bridge
curl -o lib/vk-bridge.min.js https://unpkg.com/@vkontakte/vk-bridge/dist/browser.min.js

# 2. Запустите локальный сервер
npx serve .
# или python3 -m http.server 8000

# 3. Откройте http://localhost:3000?dev=true
